# 手机端作品集文字两侧布局设计

## 目标

在不改变作品集球形画廊内容、拖动交互和桌面端排版的前提下，修正手机端当前作品文字的位置：

- 页面标题“我的作品集”继续位于页面顶部。
- 当前作品主标题（例如“人物”）位于中央作品圆片左侧。
- 当前作品小标题（例如“ai写实人物制作”）位于中央作品圆片右侧。
- 两段文字围绕画廊视觉中心垂直居中，不再停留在页面底部。

## 响应式布局

改动仅在 `max-width: 760px` 生效。

- `.infinite-menu-active-title` 使用绝对定位，锚定在画廊左侧安全边距。
- `.infinite-menu-active-description` 使用绝对定位，锚定在画廊右侧安全边距。
- 两者统一使用 `top: 50%` 和 `translateY(-50%)` 对齐中央作品圆片。
- 左右文字分别限制最大宽度，并使用适合手机屏幕的响应式字号，防止换行后遮挡作品。
- 画廊画布、圆片尺寸、图片内容和拖动逻辑保持不变。

## 视觉规则

- 主标题保持白色粗体，左对齐。
- 小标题使用浅灰色，右对齐，字号小于主标题。
- 文字层级高于画布，但不覆盖中央作品圆片的主要视觉区域。
- 页面顶部标题保留现有样式，不参与左右布局。

## 验证

- 在 390 × 844 手机视口检查主标题位于中央圆片左侧、小标题位于右侧。
- 确认两段文字没有被屏幕边缘裁切。
- 确认作品圆片、图片和拖动交互仍然可见且可用。
- 在桌面视口确认原排版没有变化。
- 运行现有 HTML 完整性测试和 Vite 生产构建。
